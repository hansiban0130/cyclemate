Oy — the companion

A moon, not an embryo. It stands for the cycle, not the outcome: it waxes through stimulation, is full at transfer, and starts again if the cycle fails. Patients are never asked to bond with an embryo. Oy reacts to the daily check-in and fronts the assistant, so "asking the clinic" feels like talking to someone, not filing a ticket.

Problem → feature

  • Uncertainty ("what happens next?") → Cycle timeline
  • Daily load → Today's plan, max 3 tasks
  • Feeling alone → 10-second check-in; coordinator reaches out first
  • Nowhere to ask → Assistant for general, doctor for medical
  • Cost anxiety → Running total, no surprises
  • Distance → 4 essential visits; rest remote or at partner clinic
  • Losing heart → 28 daily words, one per cycle day (today: day 7)
